1. Executive Summary & Architecture Overview

The Alexa+ Mission Execution Platform transforms conversational assistants into an enterprise-grade autonomous execution engine. Grounded in the official Model Context Protocol (MCP) Streamable HTTP specification (2025-11-25), Alexa+ bridges high-level user intent into structured multi-step Directed Acyclic Graph (DAG) plans, dynamically discovers registered MCP tools, executes tool calls with sub-50ms latency, and streams real-time step progress over Server-Sent Events (SSE).

Core Architectural Tenet: Zero Deceptive Claims. The application operates under a verified Honest Capability Model. Local capabilities (Calendar, Documents, Knowledge Base) run via real SQLite persistence and self-hosted MCP server tools. Simulated integrations (Slack, Gmail, Notion) are explicitly labeled with DEMO CAPABILITY badges rather than fake OAuth flows.

3. SQLite Persistence Schema Specification

The platform stores all state in data/alexa_plus.db (or fallback built-in node:sqlite). The schema consists of 9 relational tables with enforced foreign key cascades:

Table Name Primary Key Foreign Keys Key Columns & Data Types Durability Role
conversations id TEXT None title TEXT, model_id TEXT, status TEXT, created_at TEXT, updated_at TEXT Root container for grouped mission sessions.
missions id TEXT conversation_id → conversations(id) title TEXT, goal TEXT, status TEXT, duration_ms INTEGER, result_summary TEXT, started_at TEXT, completed_at TEXT Top-level mission execution entity tracking full lifecycle.
mission_steps id TEXT mission_id → missions(id) step_number INTEGER, title TEXT, phase TEXT, status TEXT, duration_ms INTEGER, result_text TEXT Individual DAG nodes (Understand, Plan, Tools, Verify, Result).
tool_calls id TEXT step_id → mission_steps(id) tool_name TEXT, arguments_json TEXT, result_json TEXT, status TEXT, latency_ms INTEGER Immutable record of every MCP RPC call executed over port 3001.
calendar_events id TEXT None title TEXT, start_time TEXT, end_time TEXT, platform TEXT, attendees TEXT, description TEXT, has_agenda INTEGER Persistent calendar schedule queried by calendar_get_events.
documents id TEXT None title TEXT, filename TEXT, file_type TEXT, category TEXT, page_count INTEGER, size_mb REAL, content TEXT Original uploaded documents with metadata.
knowledge_chunks id TEXT document_id → documents(id) chunk_index INTEGER, content TEXT, token_count INTEGER, created_at TEXT Sliced text chunks queried by knowledge_search MCP tool.
activity_events id TEXT mission_id → missions(id) event_type TEXT, category TEXT, severity TEXT, message TEXT, metadata_json TEXT, created_at TEXT Chronological system audit timeline subscribed via SSE.
integration_configs service_id TEXT None service_name TEXT, status TEXT, auth_type TEXT, config_json TEXT, updated_at TEXT Stores credentials and Honest Capability Model statuses.
